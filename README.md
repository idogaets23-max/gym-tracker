# Gym Tracker

A personal workout log for iPhone, installed from Safari to the home screen (PWA). It logs strength workouts and jiu-jitsu sessions, works offline, and keeps all data on the phone (IndexedDB).

- `npm run dev`: local server
- `npm test`: unit tests
- `npm run build`: production build in `dist/`

An optional link sends each saved entry to a private GitHub repository the user configures in Settings. The token is entered on the phone and stored only there. This repository contains no data and no tokens.
